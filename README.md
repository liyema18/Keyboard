# Blank Keys Android Keyboard

Starter source for a native Android keyboard with blank keycaps and a basic QWERTY layout.

This source project needs to be built into an APK using Android Studio (free) or a compatible Kotlin/Gradle builder. This chat cannot directly install an APK on your phone.

## Build and install
1. Open the project in Android Studio on a computer.
2. Let Gradle sync, then choose Build > Build APK(s).
3. Install the generated APK on your Android phone.
4. Open Blank Keys, enable it in Android Settings > On-screen keyboard / Manage keyboards, then select it from the keyboard picker.

This starter has blank keys, letter typing, space, backspace, shift, enter and a basic symbols page. It does not yet include swipe typing, autocorrect, word suggestions or emoji. Test it in a notes app before relying on it.

The app does not request Internet access or send typing data.
